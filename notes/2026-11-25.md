??更倾向于对nall和underfunded判断，前面是这两个才返回后面的值，对于0，“” {}之类的无反应，
||对于代表false的值都会取后面的值
结论：写默认值用 ??，除非你确实想把 0 和 "" 也当「没有」。
2. ?. 的三条规则

只对 null / undefined 短路，空对象 {}、[]、0、"" 都不算
只保护它左边紧挨着的那一层，链条上几个可能断的地方就写几个 ?.
三种形式：obj?.prop、obj?.[key]、fn?.()
3. getCity 那个例子

return user?.address?.city ?? "未知";
