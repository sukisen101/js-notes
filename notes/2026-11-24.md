+号更偏向于字符串类型，两侧有一个字符串类型会把另一个也变成字符串类型相加
null == undefined 是什么？null === undefined 呢？
null == undefined是true null === undefined是false
"5" + 1 和 "5" - 1 为什么不同？（你应该会了）
因为'+'更偏向于字符串运算，任意一侧有字符串类型会把另一侧也转换成字符串相加
既然 == 这么乱，为什么语言还保留它？
应该是因为有null == undefined这一条特殊的相等，并且不严格相等还有需要的地方
//== 是历史遗留的容错设计，因为兼容性删不掉。工程上一律用 ===，唯一例外是 x == null 判空。
